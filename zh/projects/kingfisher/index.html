Kingfisher

一个 LLM 智能体的 Python 库：每来一个请求，就只用调用方有权使用的工具、技能和数据，现场构建一个新的智能体。

Python智能体AILLM访问控制
GitHub 源码最近更新于 2026年11月

它做什么

一旦智能体能查数据库、跑 shell、还能把工作转交给别的智能体，真正难的问题就变成了：谁能用哪些。大多数框架在代码里一次性回答这个问题，所有用户拿到的都是同一个智能体。

Kingfisher 按请求来回答。智能体、工具、技能和子智能体都是定义文件夹里的普通文件，其中一些带着锁，写明谁可以触及。请求到来时，kingfisher 只用这个调用方能触及的东西构建智能体。被锁住的部分直接不放进去，而不是放进去再拒绝，所以模型根本不知道它们存在；两个人调用同一个智能体，可能得到两个不同的智能体。

其他能力

保留每个工具结果

一轮中工具返回的结果都会以 A-0042 这样的编号归档到会话的 /records，较长的结果之后可以读回，而不必一直留在对话里。

记忆

每轮结束时，记忆整理器会整理会话记住的内容。接入存储后，用户的记忆会跟着他们进入新的会话。

可替换的部件

会话、运行事件、说明和 wire format 都是插件：kingfisher 各自带一个实现，部署方也可以换成自己的。

任意模型接口

它基于 deepagents 运行，开箱即可对接 Anthropic 和 OpenAI 的接口；其他接口只需注册一种 wire format。
