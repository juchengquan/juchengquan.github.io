RRF (Reciprocal Rank Fusion)

一个用于RAG系统的Python库，实现了多种互惠排名融合策略。

PythonRAG信息检索融合算法
GitHub 源码最近更新于 2026年4月

解决什么问题

RAG 系统常常同时用两种方式检索：按关键词和按语义，再把两个排名列表合并。互惠排名融合（RRF）是最常用的合并方法：每个结果得分 1 / (k + 排名)，各列表的得分相加。

但检索器返回的是文本片段，而不是完整文档。一篇长文档可能在同一个列表中出现多次；如果每个片段都计分，它就可能胜过两个检索器都排在第一的短文档：

这个库在文档层面做融合，并提供五种处理重复命中的策略。

在流程中的位置

融合计算成本低、无需训练，并决定哪些候选结果会交给成本更高的重排序模型。

动手试试

两个检索器回答了同一个问题。选择一种策略，看融合后的排名如何变化；把鼠标移到某个文档上，可以看到它的片段来自哪里。

每次命中都加上 1 / (k + 排名)，重复命中会累加。在默认的 k 下，B 靠数量取胜：四个排名靠后的关键词命中。

k 越小，靠前的排名权重越大。
