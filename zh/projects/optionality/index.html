Optionality

一款轻量级工具，帮助业余兼职交易者及时获取低频期权交易信息。

Python交易工作流自动化
GitHub 源码最近更新于 2026年11月

它做什么

卖出标普 500 指数期权价差是一种慢节奏、需要耐心的交易：几个仓位分布在不同到期日，每个持有数周。大多数时候什么都不用做；但偶尔行情会逼近卖出的行权价，这时你需要及时知道，哪怕正在上班或已经睡了。

Optionality 在美股交易时段盯住这些仓位，一旦某项指标越过你设定的界线，就发消息到手机。它从不下单：它的券商客户端根本没有下单功能，一旦代码中出现下单调用，检查就会让构建失败。
