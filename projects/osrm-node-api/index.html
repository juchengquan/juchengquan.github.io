osrm-node-api

A routing service for OpenStreetMap road data, built on the OSRM engine: routes, travel-time tables, nearest roads and GPS trace matching over HTTP.

DockerRouting
Source on GitHubLast updated November 2026

What it does

osrm-node-api is a routing service for OpenStreetMap road data. Give it points on a map, and it answers four kinds of questions, using OSRM, a fast open-source routing engine:

Route

/route

The fastest way through two or more points, with turn-by-turn steps if you want them.

Table

/table

Travel times from every start (A–C) to every destination (1–3), in one call.

Nearest

/nearest

The closest points on the road to a coordinate, nearest first.

Match

/match

Snaps a noisy GPS trace onto the roads it most likely followed.

What it adds to OSRM

OSRM ships its own server, osrm-routed, which works well on a laptop. Running routing as a service needs more around it, and that layer is what this project is.
