RRF (Reciprocal Rank Fusion)

A Python library implementing various Reciprocal Rank Fusion strategies for RAG systems.

PythonRAGInformation RetrievalFusion Algorithms
Source on GitHubLast updated April 2026

What it solves

RAG systems often search two ways at once, by keywords and by meaning, and then merge the two ranked lists. Reciprocal Rank Fusion is the usual way to merge them: each result scores 1 / (k + rank), and the scores add up.

But retrievers return chunks, not documents. A long document can appear several times in one list, and if every chunk counts, it can beat a short document that both retrievers ranked first:

This library fuses at the document level and offers five strategies for handling those repeats.

Where it fits

Fusion is cheap and needs no training, and it decides which candidates the more expensive reranker gets to see.

Try it

Two retrievers have answered the same question. Pick a strategy and watch the fused ranking change; hover a document to see where its chunks came from.

Every hit adds 1 / (k + rank), and repeats add up. At the default k, B wins on volume: four low-ranked keyword hits.

Lower k makes the top ranks count for more.
